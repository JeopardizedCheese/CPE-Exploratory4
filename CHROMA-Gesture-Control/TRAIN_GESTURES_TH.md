# เทรนท่ามือ (สองมือ ใช้คำสั่งชุดเดียวกัน)

มือไหนก็สั่งได้เหมือนกัน เมื่อยมือหนึ่งก็สลับไปใช้อีกมือได้เลย ลำดับงาน: เก็บข้อมูล → เทรน/validate/test → ลองดูสด → ขับจริง
รายละเอียดคำสั่งและ flag ทั้งหมดอยู่ใน [README.md](README.md)

`PY` คือ `.\.venv-gesture\Scripts\python.exe` (Windows) หรือ `./.venv-gesture/bin/python` (Linux) รันในโฟลเดอร์นี้

## คำสั่งและท่าที่แนะนำ

| ปุ่ม | คำสั่ง | ท่าที่แนะนำ (ทีมเลือกท่าอื่นได้ สำคัญแค่ป้ายชื่อ) |
| --- | --- | --- |
| 1 | NONE | ท่าอื่นทั้งหมด: มือปล่อยสบาย, ครึ่งกำ, ระหว่างเปลี่ยนท่า |
| 2 | STOP | แบมือหันฝ่ามือเข้ากล้อง นิ้วชี้ขึ้น |
| 3 | FORWARD | ชี้นิ้วชี้ขึ้น |
| 4 | BACK | คว่ำนิ้วโป้งลง |
| 5 | LEFT | ชี้นิ้วชี้ไปทางซ้ายของจอ |
| 6 | RIGHT | ชี้นิ้วชี้ไปทางขวาของจอ |
| 7 | GRIP_OPEN | ชูสองนิ้ว (V) |
| 8 | GRIP_CLOSE | กำมือ |

กติกาสองมือ: ไม่เห็นมือหรือเห็นแต่ NONE → หยุดทันที, มือไหนทำ STOP → หยุด,
สองมือทำคำสั่งต่างกัน → หยุด (CONFLICT), นอกนั้นใช้คำสั่งที่เห็น (อีกมือพักไว้ได้)
คำสั่งขับต้องนิ่ง 0.15 วินาที คำสั่งหนีบต้องนิ่ง 0.4 วินาที และส่งครั้งเดียวต่อการทำท่าหนึ่งครั้ง

## 1. เก็บข้อมูล: session ละรอบ

```bash
PY gesture_collect.py --split train --note "ชื่อคน, สถานที่, แสง"
```
หนึ่งครั้งที่เปิดโปรแกรม = หนึ่ง session และเลือกชุดได้ครั้งเดียวตอนสร้าง (`--split train|validation|test`)
แนะนำ: train 3 session, validation 1, test 1 ถ้าได้ ให้ต่างวัน ต่างแสง ต่างคน
**ทุก session ต้องอัดครบ 8 คำสั่ง ทั้งมือซ้ายและมือขวา** และ **อัด test เป็นอันสุดท้าย**

ในโปรแกรม:
- `1`-`8` เลือกคำสั่ง, `H` สลับมือ, `N` ไปคำสั่ง/มือถัดไปที่ยังขาด
- `R` เริ่มอัด: นับถอยหลัง 2 วินาทีให้เข้าท่า แล้วเก็บ 60 ตัวอย่างใน 12 วินาที
- `S` จบก่อนกำหนด, `D` ทิ้ง take ที่กำลังอัด, `U` ย้อน take ล่าสุดที่บันทึกแล้ว (ย้ายไป `discarded/`)
- `M` ลองโมเดลล่าสุดสดๆ: แสดงว่าโมเดลอ่านเป็นอะไร พร้อมคะแนน 5 อันดับ
- จอแสดงจำนวนของ session นี้และของทั้งชุด และบอกว่าแต่ละชุดพร้อมเทรนหรือยัง (≥ 30 ตัวอย่าง ต่อคำสั่ง ต่อมือ ต่อชุด)

เคล็ดลับ:
- ให้เห็นในกล้องมือเดียว (สองมือจะไม่บันทึก) ถ้ากล้องเห็นว่าเป็นอีกมือ จะมีแถบเตือนสีแดง
- ระหว่างอัดให้ขยับช้าๆ: มุม ระยะ ความสูง หมุนข้อมือนิดหน่อย
- NONE สำคัญที่สุดสำหรับความปลอดภัย: อัดตอนเปลี่ยนท่าไปมา ปล่อยมือ เกา โบกมือ
  ท่าครึ่งๆ กลางๆ ต้องเป็น NONE ไม่ใช่คำสั่ง

## 2. เทรน, validate, test

```bash
PY gesture_train.py --inspect   # ดูจำนวนต่อชุด และบอกว่าขาดอะไร
PY gesture_train.py             # ได้ models/gesture_commands_<เวลา>.npz และ .report.json
```
- ชุด train ใช้สอนโมเดล
- ชุด validation ใช้เลือกเกณฑ์ความมั่นใจ (threshold/margin) ให้ "คำสั่งผิดที่อันตราย" (ขับผิดหรือหนีบผิด) น้อยที่สุดก่อน แล้วค่อยให้จำคำสั่งได้มากที่สุด
- ชุด test วัดผลครั้งเดียวตอนท้าย: accuracy, จำคำสั่งได้กี่ %, อ่านเป็น NONE กี่ %, คำสั่งผิดอันตรายกี่ครั้ง, แยกมือซ้าย/ขวา, ตาราง confusion
- ถ้าดูผล test แล้วไปแก้อะไร ต้องอัด test session ใหม่ ไม่งั้นตัวเลข test ไม่จริง
- ไม่มีการเขียนทับ ทุกครั้งที่เทรนได้ไฟล์ใหม่ โปรแกรมขับจะใช้ไฟล์ใหม่ล่าสุดเอง

## 3. ลองดูก่อนขับ

```bash
PY gesture_control.py --camera 0                               # preview ไม่ส่งอะไรไปหุ่น
PY gesture_control.py --camera 0 --live --robot 172.20.10.2    # หุ่นจริง
```
กด `G` เริ่ม, `SPACE`/`X` หยุด, `+`/`-` ปรับความเร็วทีละ 0.1 (0.1–1.0), `ESC` ออก
ถ้ามีคำสั่งหลุดผิดบ่อย เพิ่ม `--threshold 0.95` ถ้าอ่านเป็น NONE บ่อยเกิน ลด `--threshold`
(ค่าที่เทรนได้แสดงในจอ) หรืออัดข้อมูลเพิ่มแล้วเทรนใหม่
