# คู่มือผู้เล่น: บังคับหุ่นด้วยสองมือ

อ่านหน้านี้ให้จบก่อนลงสนาม แล้วซ้อมในโหมด PREVIEW (ไม่ต่อหุ่น) จนคล่อง

## 1. ยืนและจัดกล้อง

- ยืนหน้าเว็บแคม ห่างประมาณ 0.5–1 เมตร ให้เห็น **ทั้งสองมือ** ในภาพ
- ภาพบนจอเป็น **กระจก**: ยกมือขวา มือจะไปอยู่ครึ่งขวาของจอ
- ใช้แสงสว่างพอ ไม่ย้อนแสง อย่าให้คนอื่นเอามือเข้ากล้อง
- หันฝ่ามือเข้ากล้อง ทำท่าให้ชัด ค้างนิ่ง ๆ ตามเวลาที่บอก

```
+----------------------+----------------------+
|                      |                      |
|    มือซ้าย            |    มือขวา             |
|    = สั่งงาน           |    = ขับ              |
|                      |      +--------+      |
|                      |      | กรอบฟ้า |      |
|                      |      +--------+      |
|                      |                      |
+----------------------+----------------------+
                  เส้นกลางจอ
```

**ห้ามเอามือข้ามเส้นกลาง** และห้ามเอาสองมือไว้ฝั่งเดียวกัน หุ่นจะหยุดทันที

## 2. เริ่มเล่น (ทำตามลำดับ)

| ขั้น | มือ | ทำ | จอขึ้น |
| --- | --- | --- | --- |
| 1 | ซ้าย | ✋ แบมือ ค้าง 0.3 วินาที | `Command: READY` |
| 2 | ซ้าย | ✌ ชูสองนิ้ว ค้าง 0.8 วินาที | `START requested` แล้ว `ENABLED` |
| 3 | ขวา | ✋ แบมือไว้ **ในกรอบฟ้า** ค้าง 0.5 วินาที | `Drive ...: READY` |
| 4 | ขวา | เลื่อนมือที่แบอยู่ออกจากกรอบ | หุ่นเริ่มวิ่ง |

ถ้าต้องการ กด **G** บนคีย์บอร์ดแทนขั้น 2 ได้

## 3. มือขวา = ขับ

มือต้อง **แบ ✋ ตลอด** ขณะขับ ทิศคิดจาก **หัวหุ่น** ไม่ใช่ทิศบนสนาม

| ทำ | หุ่น |
| --- | --- |
| ✋ อยู่ในกรอบฟ้า | หยุด (พร้อมขับ) |
| ✋ เลื่อน **ขึ้น** | เดินหน้า |
| ✋ เลื่อน **ลง** | ถอยหลัง |
| ✋ เลื่อน **ซ้าย** | หมุนซ้ายอยู่กับที่ |
| ✋ เลื่อน **ขวา** | หมุนขวาอยู่กับที่ |
| ✊ กำมือ / ท่าอื่น / เอามือลง | **ล้อหยุด** |

หลังล้อหยุดด้วยวิธีใดก็ตาม ต้อง **✋ แบมือในกรอบฟ้า 0.5 วินาที** ก่อนขับต่อ
ระยะที่เลื่อนออกจากกรอบไม่มีผลกับความเร็ว ความเร็วมาจาก **เกียร์** เท่านั้น

## 4. มือซ้าย = สั่งงาน

**กฎสำคัญ: ก่อนสั่งทุกครั้งต้อง ✋ แบมือ 0.3 วินาทีก่อน** (ยกเว้น ✊ หยุด)
ค้างท่าแต่ละครั้งสั่งแค่ครั้งเดียว อยากสั่งซ้ำต้องแบมือแล้วทำใหม่

| ท่า | ค้าง | ผล |
| --- | --- | --- |
| ✋ แบมือ | 0.3 วินาที | พักมือ / พร้อมรับคำสั่งถัดไป |
| ☝ ชี้นิ้วชี้ขึ้น | 0.4 วินาที | **เปิด** ปากคีบ |
| 🤟 โป้ง + ชี้ + ก้อย | 0.4 วินาที | **ปิด** ปากคีบ (จับหิน) |
| 👍 โป้งขึ้น | 0.4 วินาที | เพิ่มเกียร์ (เร็วขึ้น) |
| 👎 โป้งลง | 0.4 วินาที | ลดเกียร์ (ช้าลง) |
| ✌ ชูสองนิ้ว | 0.8 วินาที | START หุ่นพร้อมวิ่ง |
| ✊ กำมือ | 0.5 วินาที | **STOP หุ่นหยุดทั้งหมด** (ต้อง ✌ ใหม่เพื่อเริ่มต่อ) |

ทำได้พร้อมกันสองมือ เช่น มือขวาขับเข้าไป มือซ้าย 🤟 ปิดคีบ

## 5. เกียร์

| เกียร์ | ใช้ตอน |
| --- | --- |
| 1 (เริ่มต้น) | เข้าใกล้หิน, จัดตำแหน่งปากคีบ, วางหินในโซน |
| 2 | วิ่งทางตรงระยะกลาง |
| 3 | วิ่งทางไกล ทางโล่งเท่านั้น |

เลขเกียร์แสดงที่บรรทัด `GEAR 1/3` บนจอ **ลดเป็นเกียร์ 1 ทุกครั้งก่อนเข้าใกล้หินหรือโซน**

## 6. ขั้นตอนเก็บหินหนึ่งก้อน

1. ซ้าย ✋ → ☝ เปิดคีบ
2. ขวา ขับเข้าหาหิน (เกียร์ 1 ตอนใกล้)
3. หินอยู่กลางปากคีบ → ขวา ✋ กลับเข้ากรอบ (หยุด)
4. ซ้าย ✋ → 🤟 ปิดคีบ
5. ขวา ขับไปโซนสีเดียวกับหิน (เพิ่มเกียร์ได้ระหว่างทาง: ซ้าย ✋ → 👍)
6. ในโซน: ซ้าย ✋ → 👎 ลดเกียร์, ขวาจัดตำแหน่ง
7. ซ้าย ✋ → ☝ เปิดคีบวางหิน
8. ขวา ✋ เลื่อนลง ถอยออกจากหิน

## 7. หยุดฉุกเฉิน

| ต้องการ | ทำ |
| --- | --- |
| ล้อหยุดทันที | ขวา ✊ หรือเอามือขวาลง |
| หุ่นหยุดทั้งหมด | ซ้าย ✊ ค้าง 0.5 วินาที หรือกด **X** |
| ปิดโปรแกรม | กด **Esc** (ส่งคำสั่งหยุดให้อัตโนมัติ) |
| ทุกอย่างไม่ตอบสนอง | **ยกหุ่นขึ้น / ปิดสวิตช์ไฟ** หุ่นไม่มีปุ่มหยุดฉุกเฉิน |

ถ้า Wi-Fi หลุดหรือโปรแกรมค้าง หุ่นหยุดล้อเองภายใน 0.3 วินาที

## 8. แก้ปัญหา

| อาการ | สาเหตุ / วิธีแก้ |
| --- | --- |
| ทำท่าแล้วไม่มีอะไรเกิด | ลืม ✋ แบมือซ้ายก่อน หรือค้างไม่นานพอ ดูบรรทัด `Command:` |
| มือขวาแบแล้วหุ่นไม่วิ่ง | ยังไม่ READY: ✋ ในกรอบฟ้า 0.5 วินาที หรือยังไม่ START |
| จอขึ้น `PAUSED` | หุ่นยังไม่ START หรือหลุดการเชื่อมต่อ: ซ้าย ✌ หรือกด G |
| `Robot status lost` | หุ่นไม่ตอบ: ตรวจไฟหุ่น, Wi-Fi hotspot ทีม แล้วกด G |
| `TWO HANDS ON ONE SIDE` | มือสองข้างอยู่ฝั่งเดียวกัน แยกมือไปคนละฝั่ง |
| `Hands:` ขึ้น `UNKNOWN` บ่อย | ทำท่าให้ชัดขึ้น หันฝ่ามือเข้ากล้อง เพิ่มแสง ขยับเข้าใกล้กล้อง |
| หุ่นหมุนผิดทาง | จำไว้ว่าทิศคิดจากหัวหุ่น ถ้าหุ่นหันหน้าเข้าหาเรา ซ้าย-ขวาจะกลับกัน |

บรรทัด `Hands:` บนจอบอกว่ากล้องอ่านแต่ละมือเป็นท่าอะไร เช่น `L:OPEN(0.95) R:OPEN(0.97)`
ตัวเลขในวงเล็บคือความมั่นใจ ต่ำกว่า 0.7 จะนับเป็น UNKNOWN

## 9. ซ้อมโดยไม่ต้องมีหุ่น

```bash
cd CHROMA-Gesture-Control
python gesture_control.py
```

(บน Windows: `.\.venv-gesture\Scripts\python.exe gesture_control.py`)

ซ้อมจนทำได้โดยไม่ต้องมองจอ:
1. เริ่มเล่น (หัวข้อ 2) ภายใน 3 วินาที
2. ขับครบ 4 ทิศ แล้วกลับเข้ากรอบ
3. เปิด-ปิดคีบสลับ 5 รอบ โดยไม่มีคำสั่งหลุด
4. เปลี่ยนเกียร์ 1 → 3 → 1
5. หยุดฉุกเฉินด้วยซ้าย ✊ แล้วเริ่มใหม่ด้วย ✌

คนถนัดซ้ายที่อยากขับด้วยมือซ้าย: เพิ่ม `--swap-hands` (สลับหน้าที่สองมือทั้งหมด)
